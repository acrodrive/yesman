# 9단계. 비교 모델 학습 (B1, B2, B-순응) (2026-10-07)

yesman.md 11절 9단계의 결과와 계획서와 달라진 점을 정리한 것이다. GPU pod(RTX 5090, 32 vCPU)에서 수행하였다.

## 끝났다는 기준 확인

| 기준 | 결과 |
| --- | --- |

## 학습 설정 (세 모델 공통, 9.3 공정성 규칙)

| 항목 | 값 |
| --- | --- |
| 디코더 | 8단계와 같음 (4.5 M 파라미터, 4층, 256차원, x0 예측, DDIM 10단계) |
| step 수 | 20,000 (batch 256). **검증 세트로 정했다**: B2를 6만 step 학습하며 5천 step마다 검증 세트 사람 경로 오차를 보니 1만~2만 5천 step에서 가장 낮고(0.19 m) 그 뒤 조금 올랐다(6만 step 0.203 m) |
| 최적화 | AdamW lr 2e-4, weight decay 1e-4, warmup 500, cosine decay, grad clip 1.0, EMA 없음 |
| 학습 샘플 | B1, B2: 원래 결정 20,238개. B-순응: 원래 20,238 + CF⁺ 32,439 (묶음 비율 그대로, 무작위로 뽑음) |
| 시드 | 모델마다 0, 1 (계획서 11단계 "주요 모델 시드 2개"를 미리 해 둠) |
| 시간 | 모델 하나 학습 약 3.7분, 평가(예측 + L1 판정 + 공식 채점) 약 21분 |

- **"같은 에폭"의 해석**: 계획서 8.4는 "같은 에폭과 batch 크기"라고 한다. 세 모델은 같은 20,238장면으로 학습하므로, 장면 기준 에폭이 같도록 step 수를 같게 두었다. B-순응은 장면마다 샘플이 더 많으므로 샘플 기준으로는 에폭이 적다(약 97 대 253).

## 평가 방법

- **경로 만들기** (`scripts/predict_planner.py`): 시작 노이즈를 장면 token마다 고정한다. 같은 장면이면 모델과 결정이 달라도 같은 노이즈에서 시작하므로 짝지어 비교할 수 있다. D0~D3와 검증 세트를 모두 만들어 두었다(`exp/eval/<run>/`). **D2, D3는 아직 보지 않았다(11단계).**
- **따르기 판정** (`scripts/follow_eval.py`): 모델 경로에 라벨을 만들 때와 같은 L1을 돌려 d̂을 구하고 d̂ ≈ d를 본다(6.2, 이웃 라벨 허용이 주 지표, 엄격 기준도 함께). B1, B2, B-순응은 항상 ACCEPT로 본다. **결과를 보기 전에 정한 규칙**: d̂을 정할 수 없으면(invalid, 구조적 애매함) "따르지 않음"으로 세고, 그 비율을 따로 낸다.
- **D0 주행 점수** (`scripts/score_planner.py`): NAVSIM v2 공식 채점(`run_pdm_score_one_stage.py`, navtest, non-reactive)에 미리 계산한 경로를 넘기는 agent(`yesman/precomputed_agent.py`)로 채점하고, D0 장면 11,751개만 평균한다. D0에 없는 395장면에는 모든 모델에 같은 LTF 경로를 채운다(바로 다음 프레임의 EC에만 영향이 있고 모든 모델에 같다). 사람과 등속의 D0 평균은 3단계 CSV에서 같은 방법으로 계산하였다.
- **기준점**: LTF 자체가 예측한 경로의 D0 EPDMS는 0.848이다(인코더의 경로 head). B1(결정 없음)이 0.84~0.85로 거의 같으므로 디코더가 정상적으로 학습되었다고 본다.

- **B2**는 세기 바꾸기(faster, slower)와 회전은 잘 따르지만, offset과 차선 변경은 거의 따르지 않는다(0~4%). 사람의 원래 결정에 offset과 차선 변경이 드물어서(navtest D0에서 한 구간이라도 offset이나 차선 변경이 있는 결정이 11.8%) 결정의 이 부분을 실행하는 법을 배우지 못한 것으로 본다. stop도 34%로 낮다.
- **B-순응**은 offset, 차선 변경, stop을 크게 더 따른다(3% → 40~48%, 34% → 67~77%). 대신 세기 바꾸기와 회전은 10~20%p 낮다.
- **B-순응의 차선 변경**은 25~29%가 차선 경계 근처에서 끝나 L1이 d̂을 정하지 못한다(미리 정한 규칙대로 "따르지 않음"). 차선을 바꾸다 마는 경로이다. B-순응의 CF⁺ 목표 경로는 다른 로그의 사람 경로이고 같은 결정에도 모양이 여럿이라, x0 예측이 그 평균 쪽으로 끌리는 것으로 보인다(검증 세트 CF⁺ 목표와의 ADE 1.36 m, 시작 노이즈에 따른 퍼짐 0.53 m).
- 검증 세트의 CF⁻ 따르기(실행할 수 없는 결정을 그대로 따른 비율)는 B2 31~36%, B-순응 28~30%이다. 이것은 RQ1의 답이 아니다(RQ1은 11단계에서 D2로 불가능 기준별로 본다). 참고로만 적는다.

## 계획서와 달라진 점

1. **학습 길이를 검증 세트로 정하였다** (위). navtest로는 아무것도 고르지 않았다.
2. **시드 2개를 9단계에서 미리 학습하였다.** 계획서는 11단계에서 "가능하면 시드 2개"이다. 학습이 4분이라 미리 했다.
3. **같은 에폭 = 같은 장면 수 기준 step**으로 해석하였다 (위).
4. **D0 점수는 D0 장면만 평균한다.** 3단계의 사람, 등속 점수(navtest 전체 12,146장면)와 비교할 때는 같은 D0 평균(0.946, 0.261)을 쓴다.
5. **공식 채점의 worker를 ray 대신 process pool로 바꾸었다.** 이 GPU pod에서 ray worker가 시작한 뒤 일을 받지 못하고 멈췄다(dashboard 시작 실패와 함께). 채점 코드는 같고 일을 나누는 방식만 다르다. LTF 채점이 8분 만에 정상으로 끝났다.

## 10단계로 넘길 것

- Ours는 같은 디코더, 같은 20,000 step, 같은 batch로 학습한다. 샘플은 원래 + CF⁺ + CF⁻이다. CF⁺ : CF⁻ 비율은 1 : 1에서 시작한다(14절, 6단계 결정). 학습 묶음은 약 4 : 1이므로 CF⁻를 더 자주 뽑아야 한다.
- 보이지 않는 원인 CF⁻(학습 묶음 702개)를 학습에 쓸지 정한다(6단계에서 미룬 것).
- B-순응의 차선 변경이 "바꾸다 마는" 경향은 Ours에도 나타날 수 있다. 11단계 그림에서 확인한다.
