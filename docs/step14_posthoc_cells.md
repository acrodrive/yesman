# 14단계 사후 분석 1번: 세트별 판단 x 결정–경로 x 안전

`scripts/step14_posthoc_cells.py`가 만든 표. 해석은 `docs/step14_run.md`의 "(사후 분석) 세트별 판단" 절. 새 테스트 세트에서 한 번 평가한 결과를 다시 나눈 것이다. 이 결과로 모델이나 τ를 바꾸지 않는다.
칸마다 결정 비율(시드 0·1 평균)과 그 칸에서 그린 경로의 안전율(NC·DAC·DDC 모두 통과, 두 시드의 행을 합침). 일치 = 경로가 결정을 따름(L1 판정 d̂ ≈ d). 판단이 없는 모델은 모두 ACCEPT이다. n은 100개보다 적을 때만 적었다(시드 평균).
T1은 테스트 평가에서 채점하지 않았으므로 여기서 채점했다: 무작위 1만 개(시드 0으로 뽑아 모든 모델에 같은 결정, `exp/step14/posthoc/T1_sample10k.npy`)와 판단 모델이 거부한 결정 전부. 비율은 T1 전체(75,767개), ACCEPT 칸의 안전율과 전체 안전율은 무작위 1만 개, REJECT 칸의 안전율은 거부한 결정 전부로 냈다.
